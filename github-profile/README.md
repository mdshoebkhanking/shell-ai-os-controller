## About Me

I am focused on building AI-native tools that are useful in real workflows:

- Desktop AI assistants.
- Voice-first automation.
- Local tool execution.
- Agent orchestration.
- Open-source developer infrastructure.
- Safe human-controlled automation.

My main project is **Shell AI OS Controller**, a desktop AI control layer for
chat, voice, tools, automation, Telegram, browser workflows, and runtime
diagnostics.

My product direction is simple: AI tools should be fast, understandable,
observable, and controlled by the user.

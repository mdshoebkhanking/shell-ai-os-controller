# GIF Demo Storyboards

Create short public GIFs from real app usage after final launch testing.

## Recommended GIFs

1. Install and first launch.
2. Chat response and tool readiness.
3. Voice page startup and transcript.
4. Tools catalog search.
5. Settings API key setup with secrets hidden.

## Style

- 8-15 seconds each.
- No secrets.
- No private file paths.
- Smooth cursor movement.
- Subtle captions only when needed.

# Screenshots

The primary public visual set now lives under `screenshots/current/` as real
PNG captures from the running Shell Web UI. These screenshots are used by the
README, media kit, and 16:9 Remotion landscape demo.

Current PNG files:

- `current/dashboard.png`
- `current/control.png`
- `current/gallery.png`
- `current/settings.png`
- `current/apps.png`
- `current/notes.png`
- `current/phone.png`
- `current/macros.png`

Avoid screenshots that show API keys, email addresses, Telegram chat IDs, or
private local files.

Older placeholder screenshots and previous showcase captures were removed so
the repository only presents the current Shell UI.

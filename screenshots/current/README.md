# Current UI Screenshots

These PNG images are the current public-facing visual set for Shell AI OS
Controller. They are real 1440x900 captures from the running Shell Web UI in
PyQt WebEngine, created through the Qt remote debugging capture script.

Files:

- `dashboard.png`
- `control.png`
- `gallery.png`
- `settings.png`
- `apps.png`
- `notes.png`
- `phone.png`
- `macros.png`

The Remotion landscape demo keeps a synced copy of these PNG captures in
`videos/instagram-reel/public/current-ui/`.

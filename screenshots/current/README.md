# Current SVG Showcase

These SVG images are the current public-facing visual set for Shell AI OS
Controller. They are designed from the active Shell Web UI style: dark Shell
chrome, cyan active rails, glass panels, dashboard telemetry, transcript/chart
control, voice orb, tools, Settings/API controls, Gallery, and runtime
architecture.

Files:

- `dashboard.svg`
- `chat-chart.svg`
- `voice-tools.svg`
- `tools-control.svg`
- `settings-api.svg`
- `gallery-media.svg`
- `runtime-architecture.svg`

The Remotion landscape demo keeps a synced copy of these SVGs in
`videos/instagram-reel/public/current-ui/`.

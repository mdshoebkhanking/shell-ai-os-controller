# Support

Shell AI OS Controller is an open-source project. Support is community-first
unless a future paid support option is announced.

## Best Places To Ask

- Use GitHub Issues for reproducible bugs.
- Use GitHub Discussions for setup help, ideas, and questions after the public
  repo is opened.
- Use `SECURITY.md` for private vulnerability reports.

## Before Opening An Issue

Please include:

- OS and version.
- Shell version.
- Install method.
- What you expected.
- What happened.
- Logs or screenshots with secrets removed.

Never share API keys, tokens, passwords, `.env`, private files, or personal
screenshots that expose sensitive data.

## Response Expectations

Maintainers will prioritize:

1. Security issues.
2. Installer and startup failures.
3. Voice and UI regressions.
4. Tool execution bugs.
5. Documentation improvements.

This project does not promise emergency support, guaranteed fixes, or enterprise
SLAs in the public open-source channel.

# Phase 9 Content And Education Ecosystem

Education lowers adoption friction. Shell needs short, practical content that
shows real workflows and honest limits.

## Launch Content Plan

- 60-second install walkthrough.
- 90-second chat and voice demo.
- 2-minute "open apps from chat" demo.
- 3-minute setup repair guide.
- 5-minute architecture overview.
- Telegram control safety guide.
- Windows-MCP setup and limitations guide.

## Tutorial Tracks

Beginner:

- install Shell
- add API key
- use chat
- test voice
- fix common errors

Builder:

- add a safe tool
- create a workflow
- inspect logs
- run tests
- package a release

Advanced:

- plugin manifest permissions
- agent orchestration model
- release signing roadmap
- security boundaries

## Demo Rules

- Use real UI.
- Show failures and recovery.
- Hide secrets.
- Do not imply unsupported OS behavior.
- Say when a tool is Windows-only or API-key dependent.

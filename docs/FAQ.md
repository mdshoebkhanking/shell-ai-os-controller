# FAQ

## Is Shell AI an operating system?

No. It is a desktop AI control layer that runs on top of Windows, macOS, or
Linux.

## Is it AGI?

No. Shell is a practical AI assistant with tools, automation, voice, and runtime
integrations. It should not claim consciousness or unrestricted autonomy.

## Can I use it commercially?

Yes. The project is Apache-2.0 licensed. Third-party APIs and services have
their own terms.

## Does it include API keys?

No. Users provide their own keys through `.env` or the UI.

## Can it control my PC?

Yes, when the relevant local automation tools are installed and permitted.
Dangerous actions should require confirmation or explicit opt-in.

## Does it work on all platforms?

Windows is primary. macOS/Linux are partially supported. Windows-MCP is
Windows-only.

# Roadmap

## 1.0.x Stabilization

- Keep installers reliable.
- Improve voice diagnostics.
- Replace placeholder screenshots with real public-safe media.
- Finish clean Windows acceptance testing.
- Keep production readiness at 100/100.
- Keep product language consistent with the trust framework.

## 1.1.x Open Source Growth

- Add documentation website.
- Add more first-run setup wizard polish.
- Add CI badge and release badge after GitHub publication.
- Improve contribution labels and discussion templates.
- Publish social preview assets and launch announcement content.

## 1.2.x Runtime Quality

- Reduce startup latency.
- Improve lazy loading.
- Expand structured observability.
- Add more tool readiness states.
- Add visible tool confidence and fallback explanations.

## 2.x Future Platform Work

- Plugin SDK hardening.
- Better sandboxing for external skills.
- Optional local-first model/runtime management.
- More cross-platform desktop abstractions.
- Multi-device sync and extension ecosystem design.

## Not Planned

- Fake AGI claims.
- Hidden autonomous execution.
- Unrestricted self-modification.
- Unsafe remote control defaults.

# Phase 9 Community Growth Ecosystem

The community should scale gradually around useful, safe contributions.

## Community Roles

- users
- install testers
- documentation contributors
- plugin creators
- automation creators
- maintainers
- moderators
- security reviewers

## Contributor Tracks

Beginner:

- docs fixes
- screenshots
- install test reports
- UI wording
- troubleshooting examples

Intermediate:

- tool tests
- voice diagnostics
- workflow examples
- platform-specific launch fixes

Advanced:

- plugin SDK
- sandboxing
- release engineering
- security review
- signed distribution

## Recognition

Use:

- changelog credits
- contributor list
- good-first-issue labels
- docs contributor acknowledgements
- release notes mentions

## Moderation

Community moderation should block:

- requests for hidden control
- credential sharing
- unsafe automation instructions
- harassment
- malicious plugin behavior

## Roadmap Transparency

Feature states:

- verified
- beta
- experimental
- planned
- blocked

This prevents users from confusing plans with shipped behavior.

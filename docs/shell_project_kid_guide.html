1. Sabse Simple Explanation

Shell AI ek desktop AI assistant hai. Tum usko chat ya voice se command dete ho. Phir woh decide karta hai ki kaunsa tool chalana hai: calculator, browser, file tool, Windows-MCP desktop control, agent, ya API service.

Isko ek smart control room samjho. User command bhejta hai, UI screen par aata hai, backend hub message pass karta hai, agent/brain decide karta hai, tool kaam karta hai, aur result wapas UI me reply ban kar dikhta hai.

3. Command Ka Safar

User types/speaks -> PyQt UI receives it -> shell_hub.py sends it to backend -> natural router or AI brain picks a tool/agent -> shell_tool_gateway.py or Windows-MCP runs it -> result returns to UI -> chat bubble shows text -> voice plays only when voice mode/manual listen is used
Chat mode ka rule ab sahi hai: agar user text se chat karta hai, reply text me hi aata hai. Voice automatically nahi bajti. Bubble me "Listen to this reply" option se manually sun sakte ho.

8. API Keys UI Se Real Me Add/Remove

Settings page me API keys add/remove karna sirf UI decoration nahi hai. Backend endpoints exist:

Endpoint Use
GET /api-keys List: kaunsi keys required/optional hain aur set hain ya nahi. Secret value wapas nahi bheji jati.

Supported provider names include Gemini/Google, OpenAI, Groq, Mistral, Perplexity, SambaNova, DeepSeek, Blackbox, OpenRouter, HuggingFace/HF, Bytez, OpenWeather, NewsData, AlphaVantage. Anthropic provider current catalog/API manager me listed nahi mila.

9. Safety: Dangerous Tools Locked Hain

Project me kuch tools aise hain jo code likh sakte hain, terminal command chala sakte hain, ya workflow se file read/write kar sakte hain. Yeh by default locked rahne chahiye.

Flag Meaning
SHELL_ALLOW_CODE_WRITE Shell runtime/core modules mutate karne ki permission.
SHELL_ALLOW_AGENT_PATCH agent.py patch/hotpatch karne ki permission.
SHELL_BLOCK_TERMINAL_EXEC Terminal/PowerShell/Python execution tools ko locked-down machines par disable karta hai.
SHELL_BLOCK_WORKFLOW_COMMANDS Workflow shell commands ko locked-down machines par disable karta hai.
Simple rule for kid demo: dangerous toggles off rakho. Demo me calculator, chat, catalog, settings, and safe local tools dikhana best hai.

# Code of Conduct

Shell AI OS Controller should be a respectful, practical, beginner-friendly
open-source project.

## Expected Behavior

- Be respectful and constructive.
- Explain technical feedback clearly.
- Help beginners without insulting them.
- Keep discussions focused on the project.
- Report security issues responsibly.

## Not Accepted

- Harassment or personal attacks.
- Sharing private keys, tokens, or credentials.
- Encouraging unsafe automation or hidden control.
- Spam, scams, or malicious code.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate
these expectations. Serious abuse can result in being blocked from the project.
